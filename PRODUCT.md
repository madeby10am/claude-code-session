# Product

register: product

## Users
Nik, a developer running several Claude Code sessions across VS Code tabs. Glances at the sidebar while working; needs the active session's state at a glance.

## Product purpose
A VS Code sidebar that mirrors the focused Claude Code session: activity, context use, plan usage, token rate, plus git, skills and MCP browsers. It follows the user's VS Code theme.

## Brand and tone
Quiet, utilitarian, with a small pixel-art robot as the one piece of personality. Delight is subtle, never decorative.

## Anti-references
Loud gradients, bouncy motion, gradient text, glassmorphism, mixed typefaces, anything that fights the editor theme.

## Strategic principles
- Inherit the VS Code theme and fonts; one UI face, one mono face.
- Motion under 250ms, ease-out, honors prefers-reduced-motion.
- Never add polling or heavy work to the extension host.
